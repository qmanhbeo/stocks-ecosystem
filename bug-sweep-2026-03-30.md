### 3. Second Bug-Sweep Batch: Split Integrity, RL Export Hygiene, CafeF Adjustment Freshness

Implemented in the `cb6cc1b` range.

Main changes:

- Added split-file validation in both the alpha supervised-label stack and the mirrored manual-label stack.
- Added stale-file cleanup for RL lab-matrix per-ticker exports.
- Made CafeF intraday adjustment freshness-aware instead of “exists means skip forever”.

Confirmed fixes:

- split files now reject partial states
- split files now reject duplicate ticker assignment across splits
- split files now reject unknown tickers that are not present in the raw data universe
- RL lab-matrix exports now remove obsolete `*_signal_predictions.parquet` files when a rerun exports a narrower subset

## Main Themes Across the Fixes

The recurring failure modes were:

- stale outputs being trusted indefinitely
- partial filesystem state being treated as valid source of truth
- cross-repo path assumptions drifting from the shared-root data contract
- wrapper/export scripts writing current outputs but not removing obsolete ones
- runtime contracts differing from what the docs and default commands implied

The fixes therefore concentrated on:

- validating state before reusing it
- making overwrite paths actually recover broken state
- making reruns idempotent and freshness-aware
- keeping producer and consumer path contracts aligned across the ecosystem
