# Bug Sweep 2026-04-05

Targeted sweep across `alpha-research-lab` for fetcher contract drift, pytest collection noise, and refresh-path compatibility regressions.

## What Fixed

### 1. FX / commodities fetcher kept old bool contract for legacy callers

Fixed in `alpha-research-lab/data_tools/fetch_fx_commodities.py`.

Changes:

- legacy calls with no explicit `probe_cache` now return `True` / `False` again
- probe-cache-aware calls still return `(status, cache_entry)`
- empty full-refresh hits with an existing file now keep the file and return success instead of `retryable`

Why this mattered:

- `tests/test_data_tool_refresh.py` still expects the old simple success contract
- the newer probe-cache tests need the richer status tuple
- the fetcher was accidentally breaking the legacy path while adding cache policy support

### 2. Global macro wrapper kept the same compatibility split

Fixed in `alpha-research-lab/data_tools/fetch_global_macro.py`.

Changes:

- legacy calls with no explicit `probe_cache` now return `True` / `False`
- probe-cache-aware calls still return `(status, cache_entry)`
- empty full-refresh hits with an existing file now keep the file and return success instead of `retryable`

Why this mattered:

- same contract drift as the FX fetcher
- same risk of breaking the old refresh tests while supporting probe-cache policy tests

### 3. SSI intraday fetcher restored the old 2-tuple for legacy callers

Fixed in `alpha-research-lab/data_tools/fetch_ssi_intraday.py`.

Changes:

- legacy calls with no explicit `probe_cache` now return `(ok, message)`
- probe-cache-aware calls still return `(ok, message, cache_entry)`

Why this mattered:

- `tests/test_data_tool_refresh.py` still unpacks two values
- the fetcher had been widened to three values unconditionally, which was a hard compatibility break

### 4. Host-model smoke test module stopped being collected as a pytest test

Fixed in `alpha-research-lab/data_tools/test_model_pool.py`.

Changes:

- added `__test__ = False` so pytest does not treat the script as a test module

Why this mattered:

- pytest was trying to collect `test_model(spec, day, api_key, ...)` as a real test
- that produced a fixture error on `spec` even though the file is a CLI smoke script

### 5. Fundamentals cache shim now exists for the old helper name

Already present from the same sweep in `alpha-research-lab/data_tools/fetch_all_stock_fundamentals.py`.

Changes:

- added `fetch_ticker_ratios(ticker)`
- it reuses a cached parquet if possible
- it refetches and rewrites the cache if the file is missing or corrupt

Why this mattered:

- a refresh test still called the old helper name
- the module only had the newer raw fetch path before the shim
