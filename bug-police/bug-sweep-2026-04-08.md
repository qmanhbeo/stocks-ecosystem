## Confirmed Fixes

### 1. Alpha run-summary artifacts now resolve against the real workspace contract

Fixed in:

- `alpha-research-lab/src/repo_paths.py`
- `alpha-research-lab/src/additive_selector_research.py`

Changes:

- absolute workspace paths under the old `/home/manh/stocks/...` root are now rebased to the current workspace when the target exists
- `data/...` artifact paths stored in run summaries now resolve from the workspace root, not the repo-local `alpha-research-lab/` tree
- new run summaries serialize workspace data paths as `data/...` instead of preserving dead absolute paths

Why this mattered:

- downstream consumers such as `h242` / `h243` were reading stale `/home/manh/stocks/...` paths and failing with `FileNotFoundError`
- relative `data/...` artifacts only worked when the compatibility symlink existed, which violated the documented root-data contract

### 2. RL evaluation now honors saved `data_dir` metadata

Fixed in:

- `RL-trading-agent/vn_stock_rl/evaluation/metadata.py`
- `RL-trading-agent/vn_stock_rl/evaluation/runner.py`

Changes:

- `_resolve_helper_inputs_from_meta(...)` now rehydrates `data_dir` alongside helper inputs
- `evaluate_model(...)` now defaults to `EVAL_DEFAULTS` shared paths instead of hard-coded repo-relative strings

Why this mattered:

- programmatic evaluation could ignore a model’s saved training data root and fall back to the wrong dataset
- portfolio-choice evaluation was exposed too, because `data_dir` controls the universe scan path

### 3. Shared recommendation now fails fast when required directories are missing

Fixed in `shared-recommendation/shared_recommendation/artifacts.py`.

Changes:

- required directory artifacts now raise immediately if the resolved path does not exist or is not a directory

Why this mattered:

- adapters could declare required directory artifacts and still generate candidates successfully even when the directory was absent
- that was a silent contract failure, not a stale-input warning

### 4. RL inspector CLIs now join `--data-dir` safely

Fixed in:

- `RL-trading-agent/vn_stock_rl/data_tools/inspect_stock.py`
- `RL-trading-agent/vn_stock_rl/data_tools/inspect_fx_commodities.py`

Changes:

- both CLIs now build file paths with `Path(...)/filename` instead of raw string concatenation

Why this mattered:

- `--data-dir /some/path` failed unless the caller added a trailing slash manually
- that produced false file-missing diagnostics even when the parquet existed

### 5. Extractor cooldown persistence no longer writes raw API keys to disk

Fixed in `alpha-research-lab/data_tools/extract_llm_news_features.py`.

Changes:

- persisted `api_key_cooldowns` are now keyed by short SHA-256 fingerprints instead of raw secrets
- the scheduler still reads legacy raw-key entries for backward compatibility during transition

Why this mattered:

- the earlier persistence change would have committed live API keys into `artifacts/llm_runtime/hosted_model_stats.json`
- that made the extractor improvement unsafe to push as written
