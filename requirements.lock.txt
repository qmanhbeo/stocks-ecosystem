# Stricter root lock file for reproducible workspace installs.
#
# Scope:
# - Targets CPython 3.10 on Linux x86_64.
# - Pins the direct dependency surface for the shared workspace.
# - Avoids pinning a large transitive tree from the wrong interpreter/runtime.
#
# Why this exists:
# - `requirements.txt` is the editable dev bootstrap.
# - `requirements.lock.txt` is the stricter, exact-version install surface.
#
# Usage:
#   conda create -n stocks python=3.10 -y
#   conda activate stocks
#   cd /home/manh/stocks
#   pip install -r requirements.lock.txt
#
# Notes:
# - This installs the local RL package non-editably for a tighter environment
#   than `-e ./RL-trading-agent`.
# - For truly hermetic installs, generate a hash-locked file from a clean
#   Python 3.10 env with pip-tools after this surface has been validated.
